Waifu AI Desktop - how to run
=============================

1. Download waifu-ai-vX.Y.Z-win-x64.zip from the Releases page and unzip it
   into a folder you'll keep (for example Documents\Waifu AI, not
   Downloads). The app runs from this folder. Nothing else to install.

2. Double-click "Waifu AI.exe". The app opens.
   - If Windows shows a blue "Windows protected your PC" box the first
     time, click "More info" -> "Run anyway". The app isn't code-signed
     yet, so Windows asks.
   - The first time, accept the Terms of Use, then press
     "Create your first identity".

To quit:
   Use More -> Quit at the foot of the app's left-hand rail. Your
   companions are offline until you start it again.

To make a desktop icon:
   Right-click "Waifu AI.exe" -> Send to -> Desktop (create shortcut).

Your companions, keys and settings are stored separately, in Waifu AI's
data folder under %APPDATA%, so they stay safe if you move or replace this
folder. Back them up from Settings -> Security.

To update later: Settings -> Updates -> Download, unzip the new version
into its own folder, Quit Waifu AI, and start it from the new folder. Keep
the old folder until the new one works.

Guides and FAQ: see README.md and the docs folder on the project's
GitHub page.
