# Waifu AI Desktop guide

The full reference for Waifu AI Desktop: the same help topics the app shows on its Help page, one page each.
New here? Start with [Start here](01-start-here.md).

The app labels your Hologram Companion's identity type "Codie". Wherever the guide says Hologram Companion, the app may say "Codie".
